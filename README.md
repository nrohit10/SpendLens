# SpendLens

SpendLens is an end-to-end personal finance intelligence platform designed to help users clearly understand where, why, and how their money is spent.

The project ingests raw bank and credit card statements, normalizes and validates the data through production-grade pipelines, and generates analytics-ready models for expense analysis. On top of this foundation, applied Generative AI is used to categorize transactions, detect recurring expenses, explain spending anomalies, and answer natural-language questions about personal finances.

SpendLens emphasizes:

Real-world data engineering practices

Cost-aware and reliable AI usage

Security and privacy by design

Clear business insights over dashboards

The system is built to mirror how modern data and AI platforms are designed in production environments, making it suitable as both a personal finance tool and a portfolio project demonstrating senior-level engineering skills.
